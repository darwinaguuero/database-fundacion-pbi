README

Este repositorio contiene un dashboard interactivo desarrollado en Power BI para la visualización y análisis de datos de beneficiarios de programas sociales.

🎯 Objetivo
Proporcionar una herramienta visual e interactiva para el monitoreo y análisis de:

Distribución geográfica de beneficiarios

Segmentación demográfica (edad, sexo, provincia)

Tipos de destinatarios y condiciones de riesgo

Cobertura institucional

🔧 Características Principales
1. Vista General de Beneficiarios
Total de beneficiarios activos: 5,837

Desglose por sexo: 31.25% Femenino, 68.75% Masculino

Segmentación por grupos etarios

2. Distribución Geográfica
Mapa interactivo con ubicación de beneficiarios

Desglose por provincias (Distrito Nacional, Santo Domingo, La Vega, etc.)

Gráfico de barras por cantidades provinciales

3. Análisis de Riesgo
Identificación de beneficiarios en condición de alto riesgo

Clasificación por tipo de destinatario

NNA (Niños, Niñas y Adolescentes) en situaciones vulnerables

4. Tipos de Destinatarios
NNA destinatario/a directo/a

NNA familiar

Padre, Madre o Tutor

Otro familiar mayor de edad

Cercano a la institución

Educadores Voluntarios

🛠️ Requisitos Técnicos
Power BI Desktop (versión recomendada: Septiembre 2023 o superior)

Permisos de lectura para archivos de datos

Navegador web moderno para Power BI Service (si se publica)

📥 Instalación y Uso
Opción 1: Power BI Desktop
Clona este repositorio

Abre el archivo Dashboard.pbix con Power BI Desktop

Actualiza las conexiones de datos si es necesario

Interactúa con los filtros y segmentaciones

Opción 2: Power BI Service
Publica el archivo .pbix en tu workspace de Power BI Service

Comparte con los usuarios correspondientes

Accede desde cualquier navegador web

🎨 Interactividad
El dashboard incluye:

✅ Segmentación por sexo (F/M)

✅ Filtros por provincia

✅ Tooltips informativos

✅ Navegación entre vistas

✅ Botones de reinicio/reset

📈 Fuentes de Datos
Los datos mostrados en este dashboard provienen de:

Sistema de registro de beneficiarios institucional

Datos demográficos oficiales

Informes de campo actualizados trimestralmente
